<Callout title='Not on strict semver yet' type='warn'>
	Public APIs (`GridApi`, `ColumnDef`, event payloads) can still change between releases without a formal deprecation cycle. Pin an exact version
	rather than a caret range, and check this page before upgrading.
</Callout>

Migration notes are updated whenever a release changes public behavior, exported APIs, event payloads, or
documented defaults. Each fixed version directory (e.g. [`1.4`](/docs/1.4/migration-notes)) carries its own copy
of this page describing the delta from the version before it — that copy is frozen at release time and never
edited afterward. For a plain list of what shipped in each release (not just breaking changes), see the
[Changelog](/docs/next/changelog).

## `next` (unreleased)

Tracks work that will ship in the release after [1.4](/docs/1.4).

### One data-write API: `transaction`

**Why:** rows and cells used to be written through separate methods, each with its own undo entry, result shape
and async variant. `api.transaction()` covers them all, atomically.

**What changed:** `applyTransaction`, `applyTransactionAsync`, `flushAsyncTransactions`, `batchCellValues`,
`batchCellValuesAsync`, `setCellValueAsync` and `updateRows` are removed, as are the `rowTransaction` and full
`rows` fields of `transaction()`. The type `BatchCellValueUpdate` is now `GridCellWrite`.

**Fix:** use the replacements listed in the [Changelog](/docs/next/changelog) and
[Transactions](/docs/next/transactions). The row nodes of a transaction are now at `result.rows`, and `result`
is never `null`.

### Text-only cells no longer contain `.og-cell-content`

**Why:** a cell of a column with no custom renderer only ever shows text, so its content wrapper was one more
element to style and lay out per cell. Such cells now hold their text directly and carry a `data-text-cell`
attribute. Cells of columns with a custom renderer, and the row-selection checkbox column, keep the wrapper.

**Before:**

```css
.my-grid .og-cell-content {
	font-variant-numeric: tabular-nums;
}
```

**After:** style the cell itself; it applies to both kinds of cell.

```css
.my-grid .og-cell {
	font-variant-numeric: tabular-nums;
}
```

### `.og-cell-portal-host` no longer has a box

**Why:** the host only anchors renderer containers in the DOM; as a flex box of its own it was one more container per
custom-renderer cell for every layout to walk through. It is now `display: contents`, so size, padding, background
or border set on it no longer apply.

**After:** style the renderer's container (`.og-custom-renderer-container` for React renderers,
`.og-dom-renderer-container` for DOM renderers), or the cell.

## Cutting a release

When a release is cut, maintainers run `pnpm --filter wit-grid-site docs:release:from-package` — it reads the
version from `packages/react/package.json`, snapshots `next` into a fixed version directory named after the
`major.minor`, and updates the version switcher automatically. See
[Docs Architecture](/docs/next/docs-architecture) for the full mechanics. After cutting a release, start a fresh,
empty "unreleased" section here.
