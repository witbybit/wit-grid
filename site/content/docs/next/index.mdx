Wit Grid is a React data grid backed by a framework-agnostic core. The docs are split into authored guides, generated reference pages, and file-backed examples.

## Documentation Model

- Authored guides live in `site/content/docs`.
- Generated references live in `site/generated`.
- Live examples live in `site/examples` and are read into docs at build time.
- Versioned docs use directory names such as `next` and `1.4`.

The current documentation version is `next`. Stable releases can be copied into a fixed version directory when a release is cut.
