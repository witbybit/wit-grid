Wit Grid is a React data grid backed by a framework-agnostic core. The docs are split into authored guides, generated reference pages, and file-backed examples.

## Start Here

- Install the React package in [Installation](/docs/next/installation).
- Render your first grid in [Quick Start](/docs/next/quick-start).
- Learn column shape in [Columns](/docs/next/columns).
- Choose a data strategy in [Row Models](/docs/next/row-models).
- Fold rows into groups or a tree in [Grouping & Tree Data](/docs/next/grouping).
- Nest a sub-grid under a row in [Master-Detail](/docs/next/master-detail).
- Drive the full imperative surface from [Grid API](/docs/next/grid-api).

## Documentation Model

- Authored guides live in `site/content/docs`.
- Generated references live in `site/generated`.
- Runnable examples live in `packages/examples`, the shared package the docs site and the demo app both import from, and are read into docs at build time.
- Versioned docs use directory names such as `next` and `1.4`.

The current documentation version is `next`. Stable releases can be copied into a fixed version directory when a release is cut.
