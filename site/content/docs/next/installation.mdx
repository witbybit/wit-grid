---
title: Installation
description: Add Wit Grid to a React application.
---

Install the React adapter:

```bash
pnpm add @eregister/wit-grid-react
```

The React package depends on the core package and exposes the public React API from `@eregister/wit-grid-react`.

```tsx
import { Grid } from '@eregister/wit-grid-react';
```

Use the generated [API Reference](/docs/next/api-reference) to confirm exports for the current docs build.
