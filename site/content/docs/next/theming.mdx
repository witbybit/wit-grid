---
title: Theming
description: Use built-in themes or map theme tokens into your application UI.
---

The React package exports built-in theme helpers from the core package:

```tsx
import { BUILT_IN_THEMES, getBuiltInTheme, themeToCSSVariables } from '@eregister/wit-grid-react';
```

Use `themeToCSSVariables` when you want to bridge grid theme tokens into a host stylesheet.
