Application code coordinates with the grid through `GridApi`. Get a handle either from `onGridReady` or with the
`useGridApi()` hook anywhere inside a `<Grid>` subtree:

```tsx
import { useGridApi } from '@eregister/wit-grid-react';

function Toolbar() {
	const api = useGridApi();
	return <button onClick={() => api.expandAllGroups()}>Expand all</button>;
}
```

## Batching writes

Use `batchCellValues` to apply several cell writes as a single undo entry, instead of calling `setCellValue`
in a loop:

```typescript
api.batchCellValues(
	[
		{ rowId: 'S-1001', colField: 'revenue', value: 150000 },
		{ rowId: 'S-1001', colField: 'opex', value: 80000 },
	],
	'api'
);
```

## Clipboard

```typescript
await api.copySelectedRange(); // copy the current selection as TSV
await api.copyRange(0, 4, 1, 3); // copy an explicit visual-index range
await api.pasteFromClipboard(); // paste TSV at the current selection anchor
```

See the full walkthrough in [Clipboard](/docs/next/clipboard).
