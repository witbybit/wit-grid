Application code coordinates with the grid through `GridApi`. Get a handle either from `onGridReady` or with the
`useGridApi()` hook anywhere inside a `<Grid>` subtree:

```tsx
import { useGridApi } from '@eregister/wit-grid-react';

function Toolbar() {
	const api = useGridApi();
	return <button onClick={() => api.expandAllGroups()}>Expand all</button>;
}
```

## State & cells

| Method            | Signature                                     | Description                                  |
| ----------------- | --------------------------------------------- | -------------------------------------------- |
| `getState`        | `() => GridStateSnapshot`                     | Full synchronous state snapshot.             |
| `getCellValue`    | `(rowId, colField) => unknown`                | Read the current value of a cell.            |
| `setCellValue`    | `(rowId, colField, value) => GridWriteResult` | Write a cell, journaling an undo entry.      |
| `batchCellValues` | `(updates, source?) => GridWriteResult`       | Apply several cell writes as one undo entry. |
| `subscribeToKey`  | `(key, listener) => () => void`               | Subscribe to updates for one coordinate key. |

## Selection & focus

| Method            | Signature                             | Description                                                |
| ----------------- | ------------------------------------- | ---------------------------------------------------------- |
| `selectCell`      | `(pointer, source?) => void`          | Set active cell focus.                                     |
| `selectRange`     | `(start, end, source?) => void`       | Highlight a rectangular selection.                         |
| `getRowIndexById` | `(rowId) => number \| undefined`      | Visual index for a row id.                                 |
| `getRowNode`      | `(rowId) => GridRowNode \| undefined` | Public row-node facade — data, selection, expansion state. |

## Columns

| Method               | Signature                      | Description                                 |
| -------------------- | ------------------------------ | ------------------------------------------- |
| `setColumns`         | `(columns) => void`            | Replace the active column schema.           |
| `setColumnWidth`     | `(colField, width) => void`    | Resize a column.                            |
| `setColumnVisible`   | `(colField, visible) => void`  | Show or hide a column without removing it.  |
| `autoSizeColumn`     | `(colField, options?) => void` | Fit one column to its widest rendered cell. |
| `autoSizeAllColumns` | `(options?) => void`           | Fit every visible column at once.           |

## Batching writes

Use `batchCellValues` to apply several cell writes as a single undo entry, instead of calling `setCellValue`
in a loop:

```typescript
api.batchCellValues(
	[
		{ rowId: 'S-1001', colField: 'revenue', value: 150000 },
		{ rowId: 'S-1001', colField: 'opex', value: 80000 },
	],
	'api'
);
```
