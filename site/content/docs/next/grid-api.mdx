Application code coordinates with the grid through `GridApi`. Get a handle either from `onGridReady` or with the
`useGridApi()` hook anywhere inside a `<Grid>` subtree:

```tsx
import { useGridApi } from '@eregister/wit-grid-react';

function Toolbar() {
	const api = useGridApi();
	return <button onClick={() => api.expandAll()}>Expand all</button>;
}
```

## Batching writes

Use `transaction` to write several cells, or rows and cells together, as a single undo entry, instead of calling
`setCellValue` in a loop. Pass `{ async: true }` to queue it with other high-frequency writes and get a promise
back. See [Transactions](/docs/next/transactions).

```typescript
api.transaction({
	cells: [
		{ rowId: 'S-1001', colField: 'revenue', value: 150000 },
		{ rowId: 'S-1001', colField: 'opex', value: 80000 },
	],
});
```

## Clipboard

```typescript
await api.copySelectedRange(); // copy the current selection as TSV
await api.copyRange(0, 4, 1, 3); // copy an explicit visual-index range
await api.pasteFromClipboard(); // paste TSV at the current selection anchor
```

See the full walkthrough in [Clipboard](/docs/next/clipboard).

## Presence, minimap and views

| Call                                     | What it does                                                  |
| ---------------------------------------- | ------------------------------------------------------------- |
| `setPresence(peers)` / `getPresence()`   | Teammates' cell cursors — see [Presence](/docs/next/presence) |
| `flashCells(cells)`                      | Briefly highlight cells                                       |
| `setShowMinimap(on)` / `setMinimapMarks` | The [minimap](/docs/next/minimap) and your marks on it        |
| `setView(config)` / `getView()`          | [Gallery or calendar](/docs/next/views); `null` for the table |
| `getVisibleRowRange()`                   | The displayed rows in view, next to `getVisibleColumnRange()` |
