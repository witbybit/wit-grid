<Tabs items={['pnpm', 'npm', 'yarn']}>
	<Tab value='pnpm'>```bash pnpm add @eregister/wit-grid-react ```</Tab>
	<Tab value='npm'>```bash npm install @eregister/wit-grid-react ```</Tab>
	<Tab value='yarn'>```bash yarn add @eregister/wit-grid-react ```</Tab>
</Tabs>

The React package depends on the core package and exposes the public React API from `@eregister/wit-grid-react`.

```tsx
import { Grid } from '@eregister/wit-grid-react';
```

<Callout title='Pin an exact version' type='warn'>
	Wit Grid does not yet guarantee strict semver stability — pin an exact version rather than a caret range. See [Migration
	Notes](/docs/1.4/migration-notes) for what changes between releases.
</Callout>
