## Candidate ranking and semantic guard decision

| Rank | Slice                                     | Delete / expected scope                                                                                                                                                                                                 | Safety and coverage                                                                                                                  | Result               |
| ---- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------- |
| 1    | Row-transaction compatibility shell       | `TransactionalRowModel`, cast/getter, fallback branch, client `applyTransaction`, duplicated collector; expected 1 protocol + 2 helpers + 1 method, roughly 70–120 LOC across `rowModel.ts` and `GridDomainMutation.ts` | focused transaction, rollback, formula, event/history, server/infinite rejection, API/pack/bench/recorder gates; one-commit rollback | **Select: Plan 165** |
| 2    | Public API/runtime composition forwarding | likely no safe deletion; 285-line composition boundary                                                                                                                                                                  | stable package API and host lifecycle depend on it                                                                                   | reject               |
| 3    | Renderer coordinator merger               | would move rather than delete several concepts                                                                                                                                                                          | phase/epoch/scroll/DOM isolation not proven duplicate                                                                                | reject               |

No new semantic guard is justified: the deletion is enforced more durably by absence of the deleted exported/internal capability plus behavior tests. Import/source-string guards would recreate the brittleness this program is intended to remove.
