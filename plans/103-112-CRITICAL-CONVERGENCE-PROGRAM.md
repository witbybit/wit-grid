# Wit Grid Critical Convergence Program — Plans 103–112

## Why Plan 103 changed

The former Plan 103 attempted to cut the foundation while the canonical mutation boundary was still incomplete. That sequencing was incorrect. Plan 103 is now the immediate architectural blocker, and the alpha foundation cut moves to Plan 112.

### Milestone

## Program success criteria

After Plan 112, the normal execution story must be explainable as:

```text
intent
→ typed domain command
→ domain owner
→ atomic commit record
→ declared versions/events/invalidation/history
→ one frame coordinator
→ physical renderer
→ optional adapter bridge
```

The row path must be explainable as:

```text
source rows
→ authoritative row model
→ derived visual rows
→ geometry
→ viewport
→ physical slots
```

Anything outside these flows must have a narrow, named reason.

## Global forbidden patterns

- New abstraction beside old abstraction.
- Renderer-owned domain mutation.
- State-reaction reconstruction of normal command side effects.
- Direct render RAF outside the authority without an allowlisted reason.
- Optional physical identity for pooled portals.
- Public exposure of mutable runtime internals.
- Completion claims without clean-checkout and behavioral evidence.
